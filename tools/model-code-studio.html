      مش لأن المتصفح ما يقدرش. النص ده بيتخزن في إعدادات متجرك وبيتبعت مع كل زيارة للصفحة، فكل كيلوبايت زيادة بيتحمّل على كل زائر — على الموبايل. والأسوأ إن محرّر الثيم نفسه بيهنّج وانت بتلصق نص ضخم، قبل ما الحقل يستلمه. عشان كده الحد ٤٠٠ ألف حرف (حوالي ٣٠٠ كيلوبايت مجسم)، وأي لصق أكبر بيتم رفضه قبل ما يتقرأ — والمشهد بيرجع للشكل المحايد والصفحة ما بتقعش.

      مجسم أكبر من كده بجد؟ ده مش مكانه هنا: ارفعه على استضافة عامة (Cloudflare R2 / S3 / GitHub Releases) واستخدم حقل الرابط اللي تحت الحقل ده.
